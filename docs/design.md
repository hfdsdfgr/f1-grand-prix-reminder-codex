# GrandPrixReminder UI

首页优先级：下一场大奖赛名称 → 开赛倒计时与当地时间 → 周末赛程 → 来源和更新时间。
重要程度通过字号、留白、宽度和位置共同表达。一个主区域配紧凑列表，辅助信息不使用与主内容等大的卡片。

采用极简、清晰的移动端工具布局：左对齐、单列、最大内容宽度 760dp，水平留白 24dp，章节间距 40dp。
赛事名称 40–48sp，倒计时 36sp，章节标题 24sp，正文 16sp，辅助信息 14sp。使用系统无衬线字体与等宽数字，避免启动时下载字体。

颜色：背景 #FFFFFF、正文 #202124、辅助文字 #5F6368、分割线 #DADCE0、强调 #B42318。
深色模式：背景 #161719、正文 #F3F4F5、辅助 #B6BBC2、分割线 #44484D、强调 #FFB4AB。
颜色集中到 theme，赛车红只用于关键状态与选中导航。无渐变、发光、卡片嵌套。

底部导航 Home / Races / Briefing / Evolution。未开发页面明确说明状态。
触控目标至少 48dp；文字支持系统缩放；小屏和横屏可滚动；不依赖动画表达信息。

Grand Prix Detail 根据生命周期渐进展示：赛前突出下一场次、完整周末赛程和提醒；比赛周末突出当前/下一 Session；赛后才加载成绩与排位。次要数据使用分隔线和留白组织，不使用同等大小的卡片矩阵。Home 与 Races 均使用带文字的原生按钮进入详情，保持可预测的返回路径和触控反馈。

赛道轮廓使用按需加载的 SVG，并通过主题色渲染；赛道图是事实数据，不使用生成式图像。无剧透模式使用设置页的单一开关，结果遮罩提供明确的「揭晓本场」操作，不能仅依赖颜色表达状态。

设计检索的 Minimalism & Swiss Style 和 Flutter LayoutBuilder 指南适用；营销落地页结构与通用蓝色配色不适用于当前产品，按本文件实现。
